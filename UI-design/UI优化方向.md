## AgentHub vs 竞品 UI 差距分析

### 一、与 OpenAI Codex 的核心差距

**1. 布局与空间利用**
- Codex 的面板系统是真正的可拆卸/可拖拽面板（detachable panes），AgentHub 目前只是 CSS Grid 固定三栏。无法将终端拖到底部、或将侧栏切换为右侧。
- Codex 支持分屏编辑器（split view），可同时查看两个文件/视图。AgentHub 单画布单视图，多任务时必须切换页面。
- 缺少"全屏专注模式"（zen mode），即一键隐藏所有 chrome，只留画布。

**2. 终端与命令行体验**
- Codex 终端是真正的 shell 模拟器，支持 ANSI 颜色、进度条、交互式命令。AgentHub 终端本质是带 prompt 的 input + 文本回显，缺少：语法高亮、命令自动补全、Ctrl+R 历史搜索、管道输出着色。
- 无法在终端中直接执行 `curl`、`npm` 等真实命令。AgentHub 的终端完全是模拟命令（`step` / `reset` / `status`），缺乏真实感。

**3. 上下文与状态可见性**
- Codex 在顶部始终显示当前模型、token 用量、会话上下文窗口填充率。AgentHub 的状态栏只有 RPM/P95/成功率等运维指标，缺少开发者关心的上下文信息。
- 没有"面包屑导航"（breadcrumb），进入深层页面后不知道自己在哪条路径上。
- 缺少会话历史/快照功能——Codex 可回溯任何一次对话。

**4. 快捷键体系**
- Codex: Ctrl+K 命令面板（command palette）、Ctrl+Shift+P 动作搜索、Ctrl+P 文件搜索。AgentHub 仅 5 个数字键跳转页面 + Ctrl+K 占位提示（无实际功能）。
- 缺少全局搜索/命令面板，用户无法用键盘完成所有操作。

**5. 视觉细节**
- Codex 的行高、字体渲染、间距节奏经过精细调校，AgentHub 的 `line-height: 1.5` 略显松散。
- Codex 有选中文本的高亮色、光标行高亮、缩进参考线，AgentHub 终端和代码块均无。
- 缺少过渡动画/微交互。Codex 面板展开有弹性缓动（spring easing），AgentHub 全无动画。

---

### 二、与 Dify / Coze（扣子）的差距

**6. 工作流可视化**
- Dify 的画布支持无限缩放、小地图（minimap）、节点自动布局、画布拖拽平移。AgentHub 的编排画布是静态定位 + SVG 连线，无缩放/平移/小地图。
- 缺少节点连接时的"磁吸"和自动路由避让，连线是硬编码的坐标。

**7. 实时协作**
- 完全缺失。无多用户光标、无评论批注、无版本 diff。Codex 和 Dify 均有多人协作。

**8. 暗色主题深度**
- AgentHub 只有一套暖调深色，无亮色模式，无高对比度模式，无自定义主题色。竞品通常支持 3-5 套预设 + 用户自定义 token。
- 缺省 `prefers-color-scheme` 媒体查询监听。

---

### 三、优先级建议（从 ROI 最高的开始）

| 优先级 | 优化项                                             | 工作量 | 收益  |
| ------ | -------------------------------------------------- | ------ | ----- |
| P0     | 终端真实感——语法高亮回显 + 命令历史 + 更多模拟命令 | 低     | 高    |
| P0     | 命令面板 Ctrl+K——全局搜索/导航/动作                | 中     | 高    |
| P1     | 面板拖拽切换位置（终端可移到底部）                 | 中     | 高    |
| P1     | 过渡动画——面板展开/收起、tab 切换、toast           | 低     | 中    |
| P1     | 状态栏增加 token 用量 & 上下文窗口                 | 低     | 中    |
| P2     | 面包屑导航                                         | 低     | 低-中 |
| P2     | 画布缩放/平移/小地图                               | 高     | 中    |
| P3     | 多用户协作                                         | 极高   | 高    |
| P3     | 亮色/自定义主题                                    | 中     | 低    |

一句话总结：**AgentHub 的骨架对了（三栏布局 + 暖调配色），但肌肉（交互细节）和神经系统（快捷键/命令面板/动画）还远不及 Codex。** 先补齐 P0/P1 即可大幅提升专业感。需要我对哪几项开始动手？
