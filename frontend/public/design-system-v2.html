Page Architecture · 路由结构

AgentHub Platform
│
├─ / (Pages Router) — 主聊天页面
│  ├─ ChatHeader           ← 会话名称、PM状态、进度条、工具按钮
│  ├─ SessionSidebar       ← 会话列表、搜索、pin
│  ├─ MessageList          ← 消息流、各类型气泡
│  │  ├─ MessageBubble     ← 文本消息

│  │  ├─ DeployCard        ← 部署卡片
│  │  ├─ DiffBubble        ← 代码差异
│  │  └─ ProgressBubble    ← 进度展示
│  ├─ ChatInput            ← 输入区、附件、@/＃/ / 提及
│  ├─ ShareDialog          ← 分享会话弹窗
│  └─ OneClickDeployModal  ← 一键部署弹窗 ★
│
├─ /admin (App Router) — 管理面板
│  ├─ GeneralSettings      ← 通用设置
│  ├─ ServiceProvider      ← 服务商管理
│  ├─ WorkflowModule       ← 工作流管理
│  ├─ SkillsModule         ← 技能库
│  ├─ UserManagement       ← 用户管理
│  ├─ AuditLogList         ← 审计日志
│  ├─ MemoryModule         ← 记忆管理
│  └─ MCPDashboard         ← MCP仪表盘
│
├─ /charts — Token 用量热力图
│
└─ /canvas — Agent 流程画布
