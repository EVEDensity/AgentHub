05 · Reference

Claude Desktop 设计参考

提取 Claude Desktop 的核心设计模式，与 AgentHub 现有设计语言进行对比与融合建议。

◧
Claude Desktop — 暗色主题

极简暗色界面

Claude Desktop 采用深色背景 (#1E1E1E) + 柔和前景色，AgentHub 的 dark 主题已对齐此方案。

☰
AgentHub — Warm 主题

温润明亮主色调

AgentHub 独创 warm 色系 — 暖灰基底配合蓝紫强调色，在技术产品中营造人文温度。

🎯 可借鉴的设计模式

1. 侧栏优先导航 — Claude Desktop 左侧会话列表 + 右侧内容区，AgentHub 已采用相同布局。

2. 上下文感知工具栏 — 根据当前状态动态显示操作按钮（如中断、部署），避免信息过载。

3. 渐进式披露 — 高级配置折叠，默认只展示核心选项，AgentHub DeployModal 已实现。

4. Toast 通知体系 — 非阻塞式操作反馈，AgentHub 已通过 ToastProvider 实现。

5. 代码高亮与 Diff — Claude Desktop 的代码渲染质量是标杆，AgentHub 已有完整支持。

🔧 差异化优势 (AgentHub 独有)

1. 多 Agent 编排可视化 — DAG 任务图、Agent 流程画布、PM 状态机，超越单一对话模型。

2. 一键部署集成 — 从对话直接到生产部署，Claude Desktop 无此能力。

3. 多用户协作 — 实时 Presence、Typing Indicator、权限角色，对标 Slack/Notion。

4. 记忆系统 — 持久化用户偏好和项目上下文，跨会话知识积累。

5. 三主题切换 — Warm / Light / Dark，比 Claude Desktop 的单暗色主题更灵活。

🔜 P1 导航体验优化

  • 侧栏折叠/展开动画过渡
  • 移动端响应式适配 (当前仅桌面)
  • 面包屑导航 (admin 深层页面)
  • 键盘快捷键全局提示面板

🔜 P1 视觉细节打磨

  • 消息气泡交错动画 (staggered reveal)
  • Agent 头像生成器多样化
  • 空状态插画 (empty state illustrations)
  • 加载骨架屏 (skeleton screens)

📋 P2 部署功能增强

  • 部署历史记录页面
  • 部署状态实时推送 (WebSocket)
  • 自定义域名绑定 UI
  • 环境变量批量配置

📋 P3 长期愿景

  • 自定义主题构建器 (用户品牌色)
  • 多语言国际化 (i18n)
  • 无障碍 (a11y) 全面审计
  • PWA 离线支持
