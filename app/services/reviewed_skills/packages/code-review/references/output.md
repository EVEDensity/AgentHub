# Review report template

## Findings

For each confirmed defect, provide:

- Severity and concise defect description.
- File and smallest relevant line location.
- Concrete input or event sequence that triggers the defect.
- Observed or source-supported behavior, expected behavior and practical impact.
- Reproduction or evidence, with a focused correction when supported.

When no defect is confirmed, state: "No confirmed findings within the reviewed
scope." Do not turn that statement into an approval or PASS Evidence.

## Review scope and validation

Identify the revision, comparison base and areas inspected. Separate checks
actually run, existing records consulted and checks not run. Record limitations
that could hide defects.

## Open hypotheses

List only material uncertainties, what evidence is missing and how to resolve
them. Keep hypotheses distinct from confirmed findings.
