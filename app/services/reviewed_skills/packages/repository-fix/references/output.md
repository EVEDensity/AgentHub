# Fix report template

Use only sections supported by the actual work. Replace placeholders with
observations; do not manufacture identifiers, test counts or successful checks.

## Result

Describe the trigger, previous behavior and behavior after the change.

## Changed files

- File and relevant line: what changed and why it is needed.

## Validation

- Command or existing CI record: actual exit status, result and scope covered.
- Checks not run or skipped: reason and resulting uncertainty.

## Remaining limits

State unresolved issues, compatibility considerations and any required external
verification. Include Artifact IDs or digests only if the host actually
registered them. Do not label this self-authored report as PASS Evidence.
